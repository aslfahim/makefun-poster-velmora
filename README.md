VELMORA — a travel poster for a city that floats above a sea of clouds. A small
self-contained Node program paints the poster pixel by pixel: a sunset sky, a
low sun, three floating isles with lamplit houses and waterfalls that spill off
their rims, a drifting airship, and the city's name set by hand in stroke
lettering at the top. It writes one PNG to /output/entry.png.

## Run it

```sh
node main.ts
```
